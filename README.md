## About Me

My route into software development did not follow the path I initially expected. I wanted to study Computer Science, but completed a Diploma in Electrical and Electronics Engineering from Dhaka Polytechnic Institute. That journey strengthened my technical mindset, while software remained the career I wanted to pursue.

My interest in coding became serious when I saw how software could turn an idea into a working product. I started with web fundamentals, built a foundation in HTML, CSS, JavaScript, TypeScript, asynchronous JavaScript, Tailwind CSS, and Git, and then moved into React and Next.js.

Today, I learn through practical projects. My current priority is becoming genuinely strong with React and Next.js before moving into backend development and the wider full stack ecosystem.

## How I Work

<table>
  <tr>
    <td width="50%" valign="top">
      <h3 align="center">Understand the Problem</h3>

        I clarify what the interface needs to achieve before writing code.
      </p>
    </td>
    <td width="50%" valign="top">
      <h3 align="center">Plan the Structure</h3>
      <p align="center">

      </p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3 align="center">Build in Small Pieces</h3>
