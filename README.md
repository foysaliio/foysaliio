# About Me

My path into software development started from a different place.

I completed a Diploma in Electronics Engineering from Dhaka Polytechnic Institute, but software was always the direction I wanted to explore seriously.

Once I started learning web development properly, I realized that I did not want to rush through technologies just to build projects. I wanted to understand the foundation underneath them.

That started with HTML, CSS, and JavaScript. Then came problem solving, asynchronous JavaScript, TypeScript, Tailwind CSS, React, and now Next.js.

A lot of my time goes into writing code, breaking things, debugging them, rebuilding them, and trying to understand why one approach is better than another.

I am currently focused on becoming a strong frontend developer while gradually building the foundation I need to move deeper into full stack software engineering.

# How I Think About Development

```text
Understand the Problem
        ↓
Understand the Data
        ↓
Break the Work Down
        ↓
Choose the Structure
        ↓
Build the First Version
        ↓
Test the Behavior
        ↓
Debug the Weak Parts
        ↓
Refactor
        ↓
Improve Again
```

I rarely understand a difficult concept completely the first time I see it.

For me, the useful part usually happens after I write the code, make a mistake, figure out why it happened, and then solve the same type of problem again.

That process has shaped most of my learning.
